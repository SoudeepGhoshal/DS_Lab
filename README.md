# Data Structures (DS) Lab

This repository contains implementations of various **Data Structures and Algorithms** covered in the **Data Structures Lab** course in Semester 3. The code is written in **C** and includes fundamental data structures along with algorithmic implementations.

---

## 🔬 Experiments

### 0️⃣ Lab 0
- **Objective:** Basics of C Programming
- **Topics Covered:** Basics

### 1️⃣ Lab 1
- **Objective:** Implementation of more complex C concepts
- **Topics Covered:** Basics

### 2️⃣ Lab 2
- **Objective:** Implementation of Array operations
- **Topics Covered:** Array DS, Sparse Matrix

### 3️⃣ Lab 3
- **Objective:** Sparse Matrix operations
- **Topics Covered:** Sparse MatriX

### 4️⃣ Lab 4
- **Objective:** Implementation of Single Linked List operations
- **Topics Covered:** Linked List DS

### 5️⃣ Lab 5
- **Objective:** Implementation of Double Linked List And Circhular Linked List operations
- **Topics Covered:** Linked List DS

### 6️⃣ Lab 6
- **Objective:** Implementation of Stack operations using Arrays and Linked Lists.
- **Topics Covered:** Stack DS

### 7️⃣ Lab 7
- **Objective:** Implementation of Queue operations using Arrays and Linked Lists.
- **Topics Covered:** Linear Queue DS, Circular Queue DS

### 8️⃣ Lab 8
- **Objective:** Implementation of DEQueue and Priority Queue operations
- **Topics Covered:** DEQueue DS, Priority Queue DS

### 9️⃣ Lab 9
- **Objective:** Implementation Binary Search Tree (BST) (creation and traversal) and various Sorting algorithms
- **Topics Covered:** Binary Search Tree DS, Bubble Sort, Insertion Sort, Selection Sort, Quick Sort, Merge Sort

---

## 📌 Requirements
- C/C++ Compiler (GCC/G++)
- IDE (CodeBlocks, DevC++, VS Code, or any compatible environment)

---

## 🚀 How to Run
1. Clone this repository:
   ```bash
   git clone https://github.com/SoudeepGhoshal/DS_Lab.git
   ```
2. Navigate to a specific week's folder:
   ```bash
   cd DS_Lab/Week_1
   ```
3. Compile and run a program:
   ```bash
   gcc program1.c -o program1
   ./program1
   ```
   or for C++:
   ```bash
   g++ program1.cpp -o program1
   ./program1
   ```
